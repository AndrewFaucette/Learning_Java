# Project Title (Update)

A recreation of the game blackjack made to help me learn Java

## Instructions for Build and Use

Steps to build and/or run the software:

1. call `set JAVA_HOME=PATH_TO_JDK_HERE` in your terminal
2. call `set PATH=%JAVA_HOME%\bin;%PATH%` in your terminal
3. navigate to the repository root directory and call `java Blackjack.java`

Instructions for using the software:

1. Indicate how many players are playing
2. On each players turn, choose whether to hit or stand
3. Keep playing rounds until you're ready to quit!

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:
